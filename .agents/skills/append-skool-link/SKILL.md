# Skill: YouTube Description Skool Link Appender

Bulk appends community and educational links to the bottom of YouTube video descriptions.

## 🚀 Execution Commands

### 1. Dry Run
```bash
./venv/bin/python append_skool_link.py --dry-run
```

### 2. Live Apply
```bash
./venv/bin/python append_skool_link.py --apply
```
