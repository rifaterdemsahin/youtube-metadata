Next steps once you approve variants
Same rollout used on every packaging test on this channel.
  • 1. Pick one variant per video — A, B, or C — as the thumbnail that ships first (YouTube's Test & Compare needs a live starting thumbnail before it can test against alternates).
  • 2. Push it live: ./venv/bin/python update_video_metadata_cli.py <VIDEO_ID> --title "<chosen title>" --thumbnail thumbnails/<VIDEO_ID>_thumb_<x>.png
  • 3. Start the A/B test manually in Studio — Content → video → Details → thumbnail test icon — since the Data API can't launch Test & Compare itself.
  • 4. Run 7–14 days, let Studio pick a winner on watch time, not just raw CTR.
  • 5. No real person's likeness was generated for any of these 12 — all silhouettes, kintsugi objects, and abstract icons.
