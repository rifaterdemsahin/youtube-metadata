🔑 Authentication & Azure Key Vault Steps

1 Create Desktop App OAuth Client ID

Open Google Cloud Console Credentials (Project: deliverypilot) ↗.
Click + CREATE CREDENTIALS ➔ OAuth client ID ➔ Set Application type to Desktop App ➔ Name: YouTube Studio MCP Desktop ➔ Click CREATE ➔ DOWNLOAD JSON.

2 Save & Backup to Azure Key Vault

Save the downloaded JSON file as client_secret.json in this project root, then store it in Azure Key Vault:

az keyvault secret set --vault-name dp-kv-deliverypilot --name youtube-client-secret --file client_secret.json

3 Run OAuth Dry-Run to Authenticate

Run the dry-run command. It will open Google Chrome to complete one-time channel consent:

./venv/bin/python append_skool_link.py --dry-run

4 Backup Authorized Token to Azure Key Vault

Once the run succeeds and token.json is created, store it in Azure Key Vault:

az keyvault secret set --vault-name dp-kv-deliverypilot --name youtube-token --file token.json
