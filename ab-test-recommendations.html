CTR Report ➔

A/B Test Recommendations

Videos flagged from the Per-Video CTR Report as needing a packaging uplift, with a concrete thumbnail + title test plan for each — following the 3-variant A/B rule used on this channel: 3 thumbnails, 3 paired titles, run in YouTube Studio's Test & Compare.

🔴 High risk — re-package first
Below-median views AND below-median retention. The video isn't getting clicked much, and when it is, it isn't holding. Full repackage: new thumbnail language + new title angle, 3 variants each.
🟡 Overpromising — align the promise
Above-median views but below-median retention. The thumbnail/title is winning the click but the video doesn't pay off what it promised — test titles/thumbnails that describe the actual content more precisely instead of chasing more clicks.
🔵 Hidden gems — promote, don't repackage
Below-median views but above-median retention — the content already works. These are lower priority for a thumbnail/title A/B test and higher priority for playlists, end-screens, and Community posts to get more impressions on an asset that already converts once seen.
How each test is built
Same 3-variant rule used on every thumbnail on this channel — see the Thumbnails Studio for live examples.

Variant A — safe evolution

Keep the current visual language but sharpen it: bigger claim, higher contrast, tighter crop. Control for the test.

Variant B — curiosity/tension

An open question or incomplete visual that needs the click to resolve. Usually wins raw CTR; watch retention doesn't collapse.

Variant C — bold contrarian claim

State the outcome directly and specifically. Tends to hold retention better because it sets an accurate expectation.

Rollout playbook
  • 1. Start with High risk, biggest view-count videos first. They have the most historical traffic to learn from fastest.
  • 2. Never A/B a thumbnail without checking real CTR in Studio first. This report's risk badges are a views/retention proxy — Studio's Reach tab has the actual number and should set the baseline before you start a test.
  • 3. Run 7–14 days per test, let YouTube's Test & Compare pick a winner on watch time, not just CTR — see the CTR page playbook for why.
  • 4. Never generate a real person's likeness for a thumbnail. Leave a clean slot for a licensed/press photo cutout instead — AI faces get flagged and look uncanny.
  • 5. Overpromising videos get a title/thumbnail fix, not a bigger claim. The click problem there is already solved; retention is the leak, so test packaging that under-promises and over-delivers instead.
