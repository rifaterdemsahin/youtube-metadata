Analytics Authentication

One-click re-auth for the yt-analytics.readonly scope. The Data-API-only token used elsewhere in this repo can't pull per-video impressions/CTR — this page holds the always-current consent link so you don't have to dig it out of a script's console output each time.

Checking auth link…
Step 1 — Authorize

Click below, sign in with the Google account that owns the channel, and approve. A local script on your machine is listening for the callback — leave the terminal running.

🔐 Authorize YouTube Analytics access
This link is single-use per script run (PKCE-bound to one local callback server). If it's expired or already used, re-run python3 fetch_video_ctr.py in the repo — it writes a fresh link into auth_url.json, which this page reads automatically. No need to edit this HTML again.
What's being requested
  • youtube.readonly — read video/channel catalog (titles, thumbnails, publish dates)
  • yt-analytics.readonly — read per-video impressions + impressions CTR from YouTube Analytics, not exposed by the Data API

Stored separately in token_analytics.json — the existing token.json (upload/edit scopes) is untouched.

Re-running the fetch
  1. Run the script. cd youtube-metadata && python3 fetch_video_ctr.py
  2. Come back to this page and click Authorize (refresh first — it reloads the latest link from auth_url.json).
  3. Approve in the Google consent screen. You'll land on a "you may close this tab" confirmation.
  4. Check the terminal. The script writes video_ctr_data.json and exits — that's what feeds the Per-Video CTR Report.
