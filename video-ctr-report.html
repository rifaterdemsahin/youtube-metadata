Per-Video CTR & Packaging Report

Every video on the channel, ranked by views, with a packaging-risk read built from what the API actually gives us. Thumbnails included so you can eyeball each one next to its numbers.

⚠️
Real per-video CTR isn't available here. YouTube's Analytics API rejects impressions / thumbnail-CTR queries for this app across every shape tried (channel totals, per-video, per-day, single-video filter) — YouTube gates that "Reach" data to audited API clients; it's otherwise Studio-only. What follows is a proxy: views + average-view-percentage + subscriber/like/comment pull, used to flag which videos most likely have a packaging problem (thumbnail/title) versus a content problem. Click "Studio ➔" on any card for the real CTR number. See channel-wide CTR by traffic source for the one real CTR figure this repo has.
